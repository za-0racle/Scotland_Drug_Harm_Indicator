# Phase 5 - Forecasting integration fix

Date: 17 November 2026. Local correction following release candidate `fca20c5` and report commit `07b8c41`. No deployment or publication.

## Root causes and correction

**Empty chart:** `analysis/outputs/rolling_origin_predictions.csv` contains `origin` and `target`, whereas the single saved forecast uses `forecast_origin` and `target_period`. `ArtifactRepository` verifies the raw CSV against `run_manifest.json`, parses its values, and `PlatformService.query` serves them through `/api/v1/forecasting/backtest`. No target quarter is missing from the 48 source/API rows. The frontend chart period helper did not recognise `target`; the subtitle used another incomplete list of period fields. This prevented chart construction despite populated result tables.

The chart helper now accepts the saved `target` field, and the subtitle uses that same helper. Target quarters, not training cutoffs, position the historical predictions. Readable model names and a Forecast target quarter axis identify the series. Four model series remain separate across the 12 targets, 2023 Q1 to 2025 Q4. The backtest table explicitly shows model, training cutoff, target, predicted count and both 80% and 95% interval bounds; tooltips retain target/cutoff and saved intervals. No model, numerical result, interval or API contract changed.

**Overview assertion:** the reported 55/56 run used an obsolete expectation that an internal filename appears in the preview. The current baseline already replaces that assertion with the required Research link and absence of the internal filename. This is separate from chart period mapping. The application continues to expose source provenance through technical research records; exports and SHA-256 checks remain unchanged. No test assertion was removed for this fix.

## Scientific limits

These are retrospective rolling-origin predictions, not current future forecasts. The 12 targets were also used for model selection; they do not provide an independent post-selection test or reliable interval calibration. Existing publication-vintage and model-interval qualifications remain. Frozen outputs, manifests, backend implementation and scientific methods are unchanged.
