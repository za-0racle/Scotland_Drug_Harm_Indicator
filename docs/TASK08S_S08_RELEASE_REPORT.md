# SDHI S08 monitoring charts and approved publication

18 November 2026. The owner explicitly approved both dedicated S08 chart implementation and publication of the completed work. This supersedes the earlier reports' publication restrictions and S08 deferral; those reports remain historical records.

## Implementation

Original monitoring results now offer configuration-specific charts through the existing configuration selector. Selecting all configurations retains the complete current-page table without mixing methods on one chart. The selector and explanation precede the chart.

EWMA shows the saved residual-scale statistic and exact per-quarter upper/lower control limits. CUSUM shows separate positive and negative components and the saved upper decision limit. Limits are dashed. Zero is not presented as a lower CUSUM alarm limit. Recorded flagged quarters are listed separately, without inferring which component crossed a limit. Neither thresholds nor flags are recomputed.

The display sorts verified year/quarter fields, preserves unavailable values and missing-quarter gaps, rejects duplicate configuration quarters and retains original record references. Calibration periods are not reconstructed. Coverage is explicitly the returned API page. Configuration labels, baseline descriptions and notes accompany the chart; complete records, settings and existing scientific qualifications remain inspectable. Failure to load chart settings leaves result records available with an explicit explanation.

The existing Chart.js renderer, responsive lifecycle, keyboard-operable legends and table equivalents are reused. No package, API, backend, data, manifest or statistical method changed for S08. Objectives O3 and O5 are directly supported; source distinctions and historical interpretation support O1/O2.
